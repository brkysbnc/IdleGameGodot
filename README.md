# IdleGameGodot

Godot 4.7.2 ile geliştirilen yıldız sistemi temalı idle oyun.

**Güncel hedef platform: Windows (PC).** 29 Ekim 2026 tarihli platform kararı, eski GitHub görevlerindeki Android gereksinimlerinin yerine geçer.

Projeyi Godot'ta içe aktar ve F5 ile çalıştır. Yıldıza tıklayarak yıldız tozu kazan, sağ panelden gök cisimleri ve yükseltmeler satın al.

- Orta veya sağ fare tuşuyla sürükle: yıldızın çevresinde kamerayı döndür.
- Fare tekerleği: yakınlaş / uzaklaş. **Ortala**: başlangıç görünümü.
- F1: geliştirme sürümünde test araçları.

Kurulum, izole testler ve Windows export adımları: [build rehberi](docs/BUILD.md).
Görevler ve doğrulama kaydı: [assignment durumu](docs/BOZHAN_ASSIGNMENTS.md).
