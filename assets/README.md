# Galaxy background

`galaxy.png` is an original background generated for this project with the built-in ImageGen tool on 29 October 2026. The saved image is 1774 x 887 pixels (2:1), below the assignment's 2048 x 1024 mobile texture limit. It is used by `game/star_system.tscn` as a `PanoramaSkyMaterial`. The star, rings, particles and audio are created by game code.

Final generation prompt:

> Use case: stylized-concept. Asset type: 2048x1024 equirectangular panorama sky texture for a lightweight 3D solar-system idle game. Primary request: a quiet deep-navy galaxy background with sparse fine stars and a subtle diffuse dusty blue-violet Milky Way band across the panorama. Very dark and low contrast so a golden central sun and thin orbit lines in front remain clear. Natural astronomical dust and soft nebula structure, polished game environment art. Full 360-degree latitude-longitude environment map, 2:1 aspect ratio, seamless left and right edges, no horizon or ground, no planets, no foreground objects, no sun, no large bright focal object. No lettering, logos, labels, border, interface or watermark. Keep the polar regions subdued and avoid bright white patches. Output exactly 2048 by 1024 if possible.
